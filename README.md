Smart Contact Manager
A robust, full-stack web application built with Spring Boot to help users manage their personal and professional contacts securely. This project follows the MVC (Model-View-Controller) design pattern and uses MySQL for data persistence.

🚀 Key Features
Secure Authentication: User registration and login powered by Spring Security.

Contact Management: Create, Read, Update, and Delete (CRUD) operations for personal contacts.

Image Uploads: Support for profile pictures for both users and individual contacts.

Dynamic UI: Responsive front-end built with Thymeleaf and Tailwind CSS (or Bootstrap).

Search Functionality: Real-time search to quickly find specific contacts.

Data Validation: Server-side validation using Hibernate Validator.

🛠️ Tech Stack
Backend: Java 17+, Spring Boot 3.x

Security: Spring Security (OAuth2/Form-based)

Database: MySQL

ORM: Spring Data JPA (Hibernate)

Template Engine: Thymeleaf

Build Tool: Maven

📋 Prerequisites
Java Development Kit (JDK) 17 or higher.

MySQL Server running locally or on a cloud instance.

Maven for dependency management.
